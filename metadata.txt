# GitHub Repository Metadata

## Repository Description (one-liner, 350 char max)

Distributed ARP-based network discovery and Wake-on-LAN. A command hub with a responsive web UI drives lightweight agents deployed across your networks over mutual TLS. Agents dial out, so no inbound firewall rules. Runs on hosts, Docker, Podman, Kubernetes and Proxmox LXC. Two static Go binaries, zero third-party dependencies.


## Short Description (for social sharing / pinned repos)

Find every host on every network, wake any machine. One hub, agents everywhere, mutual TLS between them.
